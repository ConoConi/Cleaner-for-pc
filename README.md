Короче, это самый базовый и простой клинер для пк. Он может чистить кэш компьютера, корзину, временные файлы с историей посещений Яндекс.Браузера, Google Chrome и Microsoft Edge.
Если вы обычный пользователь, вам нужно установить ДВА файла: "Cleaner.exe" и "Cleaner.cer" (это сертификат, чтобы комп доверял приложению и не блокировал его). Остальное вам попросту не нужно. Нажмите на один из них:

Сам браузер может блокировать установку, так как будет думать, что это вредоносное ПО. Чтобы установить, отключите безопасный режим в настройках.
Так же может ругаться антивирусник и блокировать запуск.
!!!!!КАК ПОСТАВИТЬ СЕРТИФИКАТ, ЧТОБЫ КОМП НЕ БЛОКАЛ ЗАПУСК!!!!!
Без этого у кого-то может выскочить "Неизвестный издатель" и заблокировать запуск. Делается один раз, 30 секунд:
1. Откройте "Cleaner.cer" (двойной клик).
2. Нажмите "Установить сертификат".
3. Выберите "Текущий пользователь", нажмите "Далее".
4. Выберите "Поместить все сертификаты в следующее хранилище", нажмите "Обзор".
5. Выберите "Доверенные корневые центры сертификации", нажмите "ОК" и "Далее".
6. Нажмите "Готово" — появится надпись, что импорт прошёл успешно.
7. Запускайте "Cleaner.exe". Теперь предупреждение про неизвестного издателя у вас уйдёт.

Если вдруг всё равно ругается - просто нажмите ЗАПУСТИТЬ В ЛЮБОМ СЛУЧАЕ, оно работает.

При каждом запуске будет выскакивать: "Разрешить ли этому приложению от неизвестного издателя вносить правки на ваш пк?"
НАЖИМАЙТЕ ДА! Без этого кэш нельзя очистить, так как нужны права администратора, которые вы предоставляете.
